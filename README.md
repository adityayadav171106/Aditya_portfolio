# Aditya Portfolio

A modern, animated personal portfolio website built with **React 19**, **Vite**, **GSAP**, and **Framer Motion**.

## ✨ Features

- Smooth scroll-based animations powered by GSAP & Framer Motion
- Custom cursor effect
- Animated preloader
- Responsive sections: Hero, About, Projects, and Contact
- Fast builds with Vite

## 🛠️ Tech Stack

| Technology | Purpose |
| :--- | :--- |
| React 19 | UI framework |
| Vite 8 | Dev server & bundler |
| GSAP | Scroll & timeline animations |
| Framer Motion | Component transitions |
| Vanilla CSS | Styling |

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/adityayadav171106/Aditya_portfolio.git
cd Aditya_portfolio/portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The site will be available at `http://localhost:5173`.

## 📜 Scripts

| Script | Description |
| :--- | :--- |
| `npm run dev` | Start the development server with HMR |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Lint the codebase with ESLint |
