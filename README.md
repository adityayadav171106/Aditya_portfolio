# Aditya_portfolio

Two implementations of the same portfolio live in this repo:

| Path | What it is |
| --- | --- |
| [`website/`](website) | **The current site** — an Angular 22 web app in an ASCII / terminal art style. |
| [`portfolio/`](portfolio) | The earlier React + Vite collage design (kept as reference content material). |

## Run the Angular site

```bash
cd website
npm install
npm start        # http://localhost:4200
npm run build    # static build in dist/website/browser
```

`website/README.md` covers the design system, interactions, theming,
accessibility notes and deployment (including GitHub Pages base href).

## Content

Copy, projects, contact links and the interests list were taken from the
`redesign` branch of this repo (`portfolio/PRODUCT.md` and its components) plus
Aditya's public GitHub repositories, so no project claims are invented.
